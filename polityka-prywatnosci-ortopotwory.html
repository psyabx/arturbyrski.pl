Polityka prywatności gry Ortopotwory: Detektywi ortografii

Obowiązuje od 11 listopada 2026.

Najważniejsze

Gra Ortopotwory nie zbiera, nie zapisuje na serwerach i nie udostępnia żadnych danych osobowych, w tym danych dzieci.

Szczegóły

  • Gra działa w całości na urządzeniu. Do grania nie potrzeba internetu i gra nie łączy się z żadnym serwerem.
  • Gra nie prosi o dostęp do lokalizacji, kamery, mikrofonu, kontaktów, plików ani internetu.
  • Gra nie zawiera reklam, narzędzi analitycznych ani zewnętrznych bibliotek śledzących.
  • Dziecko może wpisać imię swojego detektywa. Gra zapisuje tylko pierwszy wyraz (samo imię, bez nazwiska) i nie prosi o zdjęcie.
  • Postępy w nauce, imię detektywa i ustawienia są zapisywane tylko w pamięci urządzenia. Raport dla rodzica jest liczony na urządzeniu i nigdzie nie jest wysyłany. Postępy można skasować w strefie dla rodzica, a usunięcie gry usuwa wszystkie te dane.
  • Lektor czyta wyrazy wbudowanym w telefon syntezatorem mowy. Gra nie nagrywa dźwięku.
  • Jeśli w grze pojawi się zakup pełnej wersji, obsłuży go Google Play. Nie otrzymujemy danych płatniczych. Zasady Google opisuje Polityka prywatności Google.
  • Linki zewnętrzne, zakupy i ustawienia są dostępne tylko po przejściu bramki rodzicielskiej.

Strona internetowa

Strona arturbyrski.pl liczy odwiedziny narzędziem Cloudflare Web Analytics. Nie używa ciasteczek, nie zapisuje adresów IP i nie rozpoznaje pojedynczych osób. Widzimy tylko zbiorcze liczby, np. ile osób odwiedziło stronę gry i skąd przyszły. Gra tego narzędzia nie używa.

Privacy policy (English)

Ortopotwory does not collect, store on servers, or share any personal data, including children's data. The game runs entirely on the device, works offline and does not connect to any server. It requests no access to location, camera, microphone, contacts, files or the internet. The game contains no ads, analytics or tracking libraries. A child may type a name for their detective; the game keeps only the first word (a first name, no surname) and never asks for a photo. Learning progress, the detective's name and settings are stored only on the device; the parent report is calculated on the device and never sent anywhere. Progress can be reset in the parents' area, and uninstalling the game removes all of this data. Words are read aloud by the phone's built-in text-to-speech; the game does not record audio. If a full-version purchase is added, it will be processed by Google Play and we will not receive payment data. External links, purchases and settings are behind a parental gate.

The arturbyrski.pl website counts visits with Cloudflare Web Analytics, which uses no cookies, does not store IP addresses and does not identify individual people; we only see aggregate numbers. The game itself does not use it.
